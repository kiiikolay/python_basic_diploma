# Telegram-бот для поиска фильмов

Этот Telegram-бот позволяет пользователям искать информацию о фильмах, используя различные параметры, такие как бюджет, название и рейтинг.

## Особенности

-   **Поиск по названию:** Находит фильмы по точному или частичному совпадению названия.
-   **Поиск по бюджету:** Позволяет искать фильмы с большим (25000000-5000000000) или маленьким (0-25000000) бюджетом.
-   **Поиск по рейтингу:** Находит фильм с рейтингом, соответствующим заданному значению.
-   **Удобный интерфейс:** Интуитивно понятные команды и ответы бота.


## Как использовать

**Используйте команды:**
    -   `/high_budget_movie` - для получения рандомного фильма с высоким бюджетом.
    -   `/low_budget_movie` - для получения рандомного фильма с низким бюджетом.
    -   `/movie_by_rating` - для поиска фильма с указанным рейтингом.
    -   `/movie_search` - для поиска фильмов по названию.

## Установка и настройка

1.  **Клонируйте репозиторий:**
    `git clone https://github.com/kiiikolay/python_basic_diploma.git`
2.  **Установите зависимости:**
    `pip install -r requirements.txt`
3.  **Создайте файл .env с параметрами:**
    -   `BOT_TOKEN`: Токен вашего Telegram-бота, полученный от BotFather.
    -   `API_KEY`: API-ключ для доступа к базе данных фильмов.
4.  **Запустите бота:**
    `python main.py`
